The repository that hosts this website.
Usually main. Use master if that is your default branch.
Create a fine-grained personal access token at github.com/settings/personal-access-tokens, limited to this one repository, with Contents: Read and write permission.
Where does my token live?

The token is stored only in this browser (in localStorage) and is sent directly from your browser to api.github.com. It never passes through any other server, and it is not part of the published website. Anyone with the token can write to the repository you scope it to — so scope it to this repository only, and use Sign out on shared computers. If you leave "keep me signed in" unchecked, the token is forgotten when you close the tab.
